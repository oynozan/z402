This page lists every setting by component. A setting is an environment variable unless the table says it is a flag.

## Rules that apply everywhere

- **An empty variable counts as unset**, the way `VAR= command` unsets it in a shell. `NAME=` in an `.env` file brings back the default.
- **A bad value stops the start.** The process exits 1 and prints one line that starts with its name, such as `facilitator: Z402_FACILITATOR_PORT: expected a whole number from 0 to 65535`. A message names the variable and never quotes a secret, a viewing key or the contents of a keys file.
- **`NAME` and `NAME_FILE`.** Where a setting has a `_FILE` form, the variable wins over the file. The file is read and trimmed. A file that cannot be read or is empty is an error that names `NAME_FILE`.
- **Whole numbers** are written in decimal digits with no sign and no leading zero.
- **Zat amounts** are decimal strings of at most 16 digits, up to 2,100,000,000,000,000.
- **Tokens and keys** are RFC 6750 b64tokens: letters, digits and `-._~+/`, optionally ending in `=`. A token with a space or a control character is refused at start.
- **URLs** are `http://` or `https://`.
- **Paths.** For the facilitator and the demo API, a path that is not absolute is relative to the repository root, whatever directory `pnpm` runs from. For the drop box it is relative to the working directory.
- **`.env` files.** Each starter service reads `services/<name>/.env`. A variable already set in the environment wins over the file.

## Facilitator

The process is `pnpm --filter @z402/facilitator start`. Its ready lines go to stdout and everything else to stderr. See [Run the facilitator](/docs/guides/run-a-facilitator).

### Variables

| Variable | Default | Meaning |
| --- | --- | --- |
| `Z402_NETWORK` | `regtest` | `regtest`, `testnet` or `mainnet`. It picks the defaults of `Z402_LWD_URL` and `Z402_EXPECTED_BRANCH_ID`, and the address and key prefixes that are accepted. |
| `Z402_MERCHANT_KEYS_FILE` | none | The operator's keys: the JSON that `zdecrypt keygen` prints, or the view-only file that `merchant-keygen.mjs --view-only` writes. Only `orchardOnlyAddress` and `uivk` are used, and only for the two variables below that are not set. A file with a `seedHex` or `ufvk` key is refused on mainnet and gives a warning elsewhere. |
| `Z402_PAY_TO` | `orchardOnlyAddress` of the keys file | The operator's shielded-only unified address: `uregtest1...`, `utest1...` or `u1...`, and the ZIP 316 revision 2 `zu...` forms. Required unless the keys file has it. At most 1,024 characters, else `Z402_PAY_TO: must be at most 1024 characters`. |
| `Z402_UIVK` | `uivk` of the keys file | The operator's unified incoming viewing key: `uivkregtest1...`, `uivktest1...` or `uivk1...`, and the revision 2 `uvi...` forms. Required unless the keys file has it. It sees deposits and cannot spend. |
| `Z402_FACILITATOR_TOKEN` | none, required | The operator's API key. Callers present it as `Authorization: Bearer <token>`. One b64token. |
| `Z402_LWD_URL` | regtest `http://127.0.0.1:28137`, testnet `https://testnet.zec.rocks:443`, mainnet none | A lightwalletd-compatible gRPC endpoint. Required on mainnet. Plain `http://` is allowed to any host on regtest and only to a loopback host elsewhere. A user name or password in the URL is ignored. |
| `Z402_EXPECTED_BRANCH_ID` | regtest `37a5165b`, testnet `77190ad9`, mainnet none | Eight hex digits. Start-up compares them with the endpoint's consensus branch id. Unset on mainnet, that check is skipped with a warning. |
| `Z402_ZDECRYPT_BIN` | `crates/zdecrypt/target/release/zdecrypt` | The decryptor. `pnpm --filter @z402/facilitator build:native` builds the default. |
| `Z402_LEDGER` | `.data/facilitator-ledger.<network>.jsonl` | The operator's ledger. One facilitator writes it at a time, through `<ledger>.lock`. |
| `Z402_PROVIDERS_DIR` | `.data/providers.<network>` | The provider registry, the registered providers' ledgers and the catalog file. Created with mode 0700. |
| `Z402_MAX_PROVIDERS` | `32` | The most providers that can register, the operator not counted. 0 to 1,000. `0` turns away new providers. |
| `Z402_REGISTRATION_TOKEN` | unset | When set, `POST /providers` needs it as a bearer token. One b64token of at least 32 characters, for example `openssl rand -hex 32`, else `Z402_REGISTRATION_TOKEN: must be at least 32 characters`. Unset leaves registration open, and every start prints `facilitator: warning: POST /providers is open to anyone: set Z402_REGISTRATION_TOKEN to require a token`. On mainnet, unset closes it unless `Z402_REGISTRATION_OPEN=1`. |
| `Z402_REGISTRATION_OPEN` | unset | `1`, or unset, else `Z402_REGISTRATION_OPEN: expected 1, or leave it unset`. Only mainnet reads it. On mainnet with no token and no `1`, registration is off: the facilitator still starts and serves, `POST /providers` answers `403 registration_disabled`, and the start prints a warning that says why. With `1` and no token, mainnet is open like the other networks, with the warning above. A token always gates registration, so `1` beside a token changes nothing. |
| `Z402_FACILITATOR_HOST` | `127.0.0.1` | The address to listen on. Anything that is not loopback prints a warning, because the only protection is the key. |
| `Z402_FACILITATOR_PORT` | `4022` | 0 to 65,535. `0` picks a free port. |
| `Z402_PRICE_ZAT` | unset | Not used. Each provider prices its own routes, from 1 zat to `windowZat`. If it is set, the facilitator prints one warning that says so. |

The loopback test accepts `localhost` in any letter case, `::1` or `[::1]`, and `127.` followed by three groups of one to three digits. Other spellings, such as `127.1`, are treated as not loopback for the listen host.

### Trust terms

The four terms are the same for every provider. `GET /supported` advertises them and each resource server copies them into its 402s. Change them only when you can restart every resource server.

| Variable | Default | Range | Meaning |
| --- | --- | --- | --- |
| `Z402_WINDOW_ZAT` | `100000` | A zat amount of at least 1 | The size of one deposit. It is also the cap on unconfirmed exposure, and the highest price a route may have. |
| `Z402_CREDIT_RATIO_BPS` | `2500` | 0 to 10,000 | Credit on confirmed deposits, in basis points. |
| `Z402_CREDIT_CAP_ZAT` | `200000` | A zat amount, 0 allowed | The most credit one session can hold. |
| `Z402_ZERO_CONF_MIN_EXPIRY_BLOCKS` | `20` | A whole number from 0 | An unconfirmed deposit earns zero-conf credit only with at least this many blocks left before it expires. |

A whole-number term is limited to ten digits. An invalid term is reported with its variable name, as `Z402_WINDOW_ZAT: windowZat must be at least 1`.

### Embedding the facilitator

`startFacilitator` from `@z402/facilitator` takes the same settings as options. Tests and `apps/e2e` call it directly. It checks every option before it opens anything, and refuses a bad one with a message that starts with the option's name and never quotes its value.

| Option | Allowed | Default |
| --- | --- | --- |
| `network`, `payTo`, `chain`, `terms` | A Zcash network, the operator's address, a chain view and the trust terms | Required |
| `priceZat` | Any value. It is neither read nor checked | Ignored: each provider prices its own routes |
| `authToken` | One b64token. Left out, a request with no `Authorization` header is the operator's | None |
| `ledgerPath` | Not blank. Left out, the ledger is in memory and takes no lock | None |
| `providers` | `{ dir, chainFor, owns, max?, registrationToken?, registrationEnabled? }`. `registrationEnabled: false` answers `POST /providers` with `registration_disabled` while the registered providers keep serving. Left out, `providers` makes `POST /providers` answer `registration_disabled` | None |
| `host` | Not blank | `127.0.0.1` |
| `port` | A whole number from 0 to 65,535 | `0`, a free port |
| `pollIntervalMs` | A whole number from 1 to 2,147,483,647 | `5000` |
| `depositWaitMs` | A whole number from 0 to 30,000 | `30000` |
| `onFatal` | A function, called once on the first failed ledger write or lost lock | None |
| `log` | A function that receives one line per request and the diagnostics | None: diagnostics go to stderr, and no request lines are written |

## Resource servers

### Shared by every starter service

Every service reads these through `loadServiceEnv` from `@z402/service-kit`. A service runs as one provider: its key and its address belong together, and `checkProvider` proves it at start.

| Variable | Default | Meaning |
| --- | --- | --- |
| `Z402_NETWORK` | `regtest` | `regtest`, `testnet` or `mainnet`. Must be the facilitator's network. |
| `Z402_FACILITATOR_URL` | none, required | The facilitator's `http://` or `https://` URL, with no user name or password in it. |
| `Z402_FACILITATOR_TOKEN`, `Z402_FACILITATOR_TOKEN_FILE` | none | The provider's API key, sent as a bearer token. The operator's token, or the key that `POST /providers` issued. |
| `Z402_PAY_TO`, `Z402_PAY_TO_FILE` | none, required | The provider's shielded-only unified address. It must be the address the API key is registered to. |
| `Z402_PRICE_ZAT` | The service's own price | Replaces the price of every route that sets none. A whole number of zat from 1 to the facilitator's `windowZat`. A service with a price outside that range refuses to start, naming `Z402_PRICE_ZAT`. |
| `PUBLIC_URL` | `http://localhost:<PORT>` | The public origin of the service, used as the `resource` URL in every 402 and in the catalog. |
| `HOST` | `127.0.0.1` | The listen address. Not blank. |
| `PORT` | Per service | 0 to 65,535. |
| `Z402_FACILITATOR_WAIT_MS` | `120000` | How long a service keeps retrying a facilitator that is starting or down, 0 to 3,600,000. `0` fails at once. A refused key, another `payTo` or a wrong answer is never retried. |

At start a service runs `checkProvider`, then reads `GET /supported`, then checks every route's price. Then it declares its routes to the catalog every 30 s while it is ready. Declaring is on by default, and there is no variable for its interval.

| `LLM_CHUNK_TOKENS` | `32` | Tokens per paid chunk, 1 to 512. |
| `LLM_MAX_TOKENS` | `1024` | The output cap per stream, and the most a call may ask for, 1 to 32,768. |
| `LLM_MAX_PROMPT_CHARS` | `8000` | The longest prompt, and separately the longest system prompt, 1 to 1,000,000. |
| `LLM_MAX_STREAMS` | `64` | Streams live at once, 1 to 100,000. |
| `LLM_STREAM_IDLE_MS` | `600000` | An untouched stream is dropped and its generation stopped, 1,000 to 86,400,000. |
| `LLM_CHUNK_TIMEOUT_MS` | `60000` | How long a paid call waits for its chunk, 1 to 60,000. |

| Variable | Default | Meaning |

| `MARKDOWN_MAX_MARKDOWN_BYTES` | `1048576` | The largest markdown answer. A longer one is cut and marked `truncated`. 1,024 to 16 MiB. |

| `MARKDOWN_MAX_REDIRECTS` | `5` | 0 to 20. |

| `MARKDOWN_MAX_CONCURRENT` | `4` | Pages fetched and converted at once, 1 to 64. More get `503 busy`. |
| `MARKDOWN_CONVERT_WORKERS` | `1` | Conversion worker threads, 1 to 16. |

| `MARKDOWN_CACHE_ENTRIES` | `100` | 1 to 100,000. |
| `MARKDOWN_CACHE_BYTES` | `33554432` | What the cached pages keep at most, 1 MiB to 1,024 MiB. |
| `MARKDOWN_USER_AGENT` | `z402-markdown/0.1` | 1 to 256 printable ASCII characters. |
| `MARKDOWN_TRUST_PROXY` | off | Express `trust proxy`: the number of proxies in front, or their addresses. `true` is refused, because the client writes the left-most `X-Forwarded-For` address itself. |

| `Z402_API_PORT` | `4021` | 0 to 65,535. |

## Agent and smoke test

The agent and the smoke test read flags and no environment variables.

### Agent

`pnpm --filter @z402/agent demo [flags]`, or `docker compose run --rm agent [flags]`.

| Flag | Default | Meaning |
| --- | --- | --- |
| `--api <url>` | `http://127.0.0.1:4021` | A merchant's base URL. `GET <url>/chunk` is the paid call. |
| `--url <url>` | none | A paid GET URL. Repeat it to call several in turn, with one session per payee. Takes the place of `--api`. |
| `--calls <n>` | `150` | Paid calls per target. |
| `--interval-ms <ms>` | `1000` | The pause between calls. `0` allowed. |
| `--cheat` | off | Deposit once, then let the merchant refuse at its credit limit. One target only. |
| `--network <id>` | `zcash:regtest` | `zcash:regtest`, `zcash:testnet` or `zcash:mainnet`. |
| `--wallet <kind>` | `zallet` | `zallet`. The parser also accepts `zingo`, which is refused until Phase 2 (mainnet). |
| `--zallet-url <url>` | `http://127.0.0.1:50232` | The Zallet JSON-RPC endpoint. |
| `--zallet-user <user>` | `zebra` | Zallet's RPC user. |
| `--zallet-password <pw>` | `zebra` | Zallet's RPC password. It shows in the process list, and the default is the public regtest one. |
| `--lightwalletd <url>` | `http://127.0.0.1:28137` | A lightwalletd or Zaino gRPC endpoint, for deposit status. |

### Discover

`pnpm --filter @z402/agent discover [flags]`, or `docker compose run --rm discover [flags]`.

| Flag | Default | Meaning |
| --- | --- | --- |
| `--discovery <url>` | `http://127.0.0.1:4022` | A Bazaar endpoint: the facilitator, or the website that proxies it. No credentials, query or fragment. |
| `--intent <text>` | none | Rank the list by word overlap with this text. It is matched on your machine and never sent. |
| `--json` | off | Print the list as the service sent it. Cannot be combined with `--intent`. |

### Smoke

`pnpm --filter @z402/smoke start [flags]`, or `docker compose run --rm smoke [flags]`. A service without its flag is skipped, and a run with no service is a flag error.

| Flag | Default | Meaning |
| --- | --- | --- |
| `--llm <url>`, `--markdown <url>`, `--embeddings <url>`, `--dropbox <url>` | none | The base URL of each service to check. No credentials, query or fragment. |
| `--page <url>` | `https://example.com` | The page the markdown service fetches. |
| `--network <id>` | `zcash:regtest` | The network. |
| `--zallet-url <url>`, `--zallet-user <user>`, `--zallet-password <pw>` | `http://127.0.0.1:50232`, `zebra`, `zebra` | Zallet, as for the agent. |
| `--lightwalletd <url>` | `http://127.0.0.1:28137` | Zaino, as for the agent. |
| `--help`, `-h` | | Print the usage and exit 0. |

Exit status: 0 when every step passed, 1 when a step failed or the wallet could not be used, 2 for a flag error. Ctrl-C ends a run with 130 and SIGTERM with 143.


| `DISCOVERY_URL`, `HOSTNAME`, `PORT` | `http://facilitator:4022`, `0.0.0.0`, `3000` | The website |

The facilitator's start command reads its token from `/run/z402/facilitator-token` and exports it as `Z402_FACILITATOR_TOKEN`. The API's reads the token and the address from the same volume.

### Docker defaults of the services

Compose reads `docker/env/<name>.env` first and then `services/<name>/.env`, which wins.

| File | Settings |
| --- | --- |
| `docker/env/llm.env` | `LLM_BASE_URL=http://llm-model:8080/v1`, `LLM_MODEL=qwen2.5-0.5b-instruct`, `PUBLIC_URL=http://localhost:4031`, `LLM_MAX_PROMPT_CHARS=1600` |
| `docker/env/embeddings.env` | `EMBEDDINGS_BASE_URL=http://embed-model:8080/v1`, `EMBEDDINGS_MODEL=nomic-embed-text`, `EMBEDDINGS_MAX_CHARS=4000`, `EMBEDDINGS_MAX_INPUT_CHARS=2000`, `PUBLIC_URL=http://localhost:4033` |
| `docker/env/dropbox.env` | `DROPBOX_LWD_URL=http://zaino:8137`, `DROPBOX_DIR=/data/dropbox`, `PUBLIC_URL=http://localhost:4034` |
| `docker/env/markdown.env` | `PUBLIC_URL=http://localhost:4032`, `MARKDOWN_CACHE_MS=120000` |

The prompt and string caps keep a call within the local models, because llama.cpp refuses a longer prompt only after the call is paid. With a hosted provider, an empty `LLM_MAX_PROMPT_CHARS=` or `EMBEDDINGS_MAX_INPUT_CHARS=` in the service's `.env` brings back the service's own limit.
